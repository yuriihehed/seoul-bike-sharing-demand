# seoul-bike-sharing-demand
Regression analysis and predictive modeling on the Seoul Bike Sharing Demand dataset using SAS. Final project for DSC 323 at DePaul University.



This project explores and models the Seoul Bike Sharing Demand dataset to predict hourly bike rental counts based on weather and seasonal variables. 
It was completed as a final project for the course DSC 323: Data Analysis & Statistical Software II at DePaul University.

## 🔍 Project Summary
- **Goal**: Predict the number of bikes rented per hour
- **Tool**: SAS
- **Dataset**: 8,760 hourly observations
- **Techniques Used**:
  - Data cleaning & preprocessing
  - Exploratory data analysis
  - Linear regression modeling
  - Multicollinearity check
  - Model refinement & validation (train/test split)
  - Prediction generation
